a listing or store with no file here just has no photo.

The rule: a listing uses the file named after its name up to the first comma, in lower
case with dashes ("Ube cheese ensaymada, box of 4" is `ube-cheese-ensaymada.jpg`). A store
uses `store-` plus the name in its page address.

Keep each file under about 500 KB and 1600 px wide; they're shrunk again when the demo
loads. Only use photos you took yourself or that are free to reuse, and credit them in
the main README if the licence asks for it.
